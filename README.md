# Service Request System

A web application for managing service requests, designed for users and support operators. The system provides request tracking, ticket organization, comments, status management, and account management.

## Features

### User Features

- User registration, login, and logout
- View and edit account information
- Create service requests with configurable parameters
- Browse an archive of submitted requests
- View request details and operator comments
- Switch between light and dark themes

### Operator Features

- Create and manage tickets to organize service requests
- Receive new requests in the default **New** ticket
- Move requests between tickets
- View request details and update request information
- Change request statuses and add comments
- Filter requests by name and category
- View ticket statistics, including the number of requests in each ticket

### General Features

- Role-based user and operator interfaces
- Request and ticket management
- Light and dark theme support

## Tech Stack

**Frontend**

- React
- TypeScript
- React Router
- SCSS

**Backend**

- C#
- ASP.NET Core
